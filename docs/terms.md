# CLI Dojo 利用規約

最終更新日: 2026-05-09

この利用規約（以下「本規約」）は、CLI Dojo（以下「本サービス」）の利用条件を定めるものです。ユーザーは、本サービスを利用することで、本規約に同意したものとみなされます。

## 1. 本サービス

本サービスは、CLI 学習用の問題回答、学習進捗管理、認証機能、およびこれらに付随する機能を提供します。

本サービスの内容は、運営上の判断により、追加、変更、停止されることがあります。

## 2. 利用登録とアカウント

- 本サービスの一部機能は、未ログインでも利用できます。
- 学習記録の保存、進捗の同期、設定機能などには、ログインが必要になる場合があります。
- ユーザーは、Email、Google、GitHub など、本サービスが提供する認証方法を用いてログインできます。
- ユーザーは、自己の責任でアカウント情報および利用端末を管理するものとします。

## 3. 禁止事項

ユーザーは、本サービスの利用にあたり、次の行為をしてはなりません。

- 法令または公序良俗に反する行為
- 不正アクセス、脆弱性探索、過度な負荷試験など、本サービスの運営に支障を与える行為
- 他者のアカウント、識別情報、学習記録、または個人情報を不正に取得、利用、改ざんする行為
- 本サービスを通じて虚偽情報、権利侵害情報、または有害なデータを送信する行為
- 本サービスのバグ、不具合、設計上の抜けを不当な利益取得のために利用する行為
- 運営者または第三者の知的財産権、名誉、信用、プライバシーその他の権利利益を侵害する行為

## 4. 学習データとフィードバック

- ログイン済みユーザーの学習記録は、サービス提供および進捗表示のために保存されます。
- 未ログイン時の一時進捗は、ブラウザの `sessionStorage` に保存されることがあります。
- ユーザーが送信したフィードバック、スクリーンショット、要望、不具合報告は、本サービスの改善、調査、品質向上のために利用されます。
- ユーザーは、フィードバック送信時に、第三者の個人情報、機密情報、権利侵害コンテンツを含めないものとします。

詳細な情報の取扱いは、別途定めるプライバシーポリシーに従います。
