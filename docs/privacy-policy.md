# CLI Dojo プライバシーポリシー

最終更新日: 2026-05-08

CLI Dojo（以下「本サービス」）は、CLI 学習アプリとしての提供、アカウント認証、学習記録の保存、およびサービス改善のために、必要最小限の情報を取り扱います。

本ポリシーは、本サービスが取得する情報、その利用目的、第三者サービスとの連携、保存・共有・削除の考え方、ならびにユーザーの選択肢を定めるものです。

## 1. 事業者情報

- サービス名: CLI Dojo
- 公開URL: https://cli-dojo.vercel.app
- 運営者リポジトリ: https://github.com/yd20250129/cli-dojo
- お問い合わせ窓口: https://github.com/yd20250129/cli-dojo/issues

## 2. 取得する情報

本サービスは、利用方法に応じて次の情報を取得します。

### 2-1. アカウント認証に関する情報

Clerk を認証基盤として利用し、Email、Google、GitHub のいずれかの方法でログインした際に、次の情報を取得または参照することがあります。

- メールアドレス
- メールアドレスの確認状態
- 表示名
- プロフィール画像
- 認証プロバイダーに紐づく外部識別子

Google または GitHub 連携時に、本サービスが直接パスワードを保存することはありません。認証は各プロバイダーまたは Clerk を通じて処理されます。

### 2-2. 学習利用に関する情報

- 回答した問題
- 選択した回答
- 正誤情報
- セクションごとの進捗
- 学習開始時刻、回答時刻、完了時刻
- 正答率や回答数などの集計結果

### 2-3. 未ログイン時の一時情報

未ログイン時の学習進捗は、ブラウザの `sessionStorage` に一時保存されます。これは同一ブラウザの同一セッション内でのみ保持され、アカウントに引き継がれない限り、サーバー側の正式な学習記録にはなりません。

### 2-4. 技術的ログ

サービス提供、障害調査、不正利用対策のために、ホスティング基盤、認証基盤、データベース基盤、アプリケーション実行環境において、次のような技術的情報が記録されることがあります。

- アクセス日時
- リクエストに関する基本情報
- エラーログ
- 監査や障害調査に必要な操作記録

## 3. 情報の利用目的

本サービスは、取得した情報を次の目的で利用します。

- ユーザー認証およびログイン状態の維持
- 学習記録、正答率、進捗状況の保存と表示
- 未ログイン進捗の一時保存およびログイン後の引き継ぎ
- 問題回答履歴に基づく学習再開機能の提供
- 不具合調査、障害対応、セキュリティ対応
- サービス品質の改善
- 利用者からの問い合わせ対応

取得した Google または GitHub アカウント情報を、広告目的で販売したり、無関係な目的で利用したりすることはありません。

## 4. Google 連携に関する取扱い

本サービスは、Google アカウントによるログインのために Google 連携を利用する場合があります。

- 利用目的は、本人確認、アカウント作成、ログイン、表示プロフィール反映に限定されます。
- 取得した Google アカウント情報は、本サービスの認証およびアカウント表示に必要な範囲でのみ利用します。
- 取得した情報を、Google 以外の第三者へ販売することはありません。
- ユーザーは、Google アカウントの権限設定画面から本サービスへのアクセス権を取り消すことができます。

本サービスは、Google API から受領した情報を、Google API Services User Data Policy が求める範囲でのみ利用します。

## 5. GitHub 連携に関する取扱い

本サービスは、GitHub アカウントによるログインのために GitHub 連携を利用する場合があります。

- 利用目的は、本人確認、アカウント作成、ログイン、表示プロフィール反映に限定されます。
- 取得した GitHub アカウント情報は、本サービスの認証およびアカウント表示に必要な範囲でのみ利用します。
- 本サービスは、GitHub リポジトリの内容変更、Issue 作成、Pull Request 操作など、ログインに不要な権限を利用しません。
- ユーザーは、GitHub のアプリ承認設定画面から本サービスへのアクセス権を取り消すことができます。

## 6. 第三者サービス

本サービスは、次の第三者サービスを利用することがあります。

- Clerk: 認証およびセッション管理
- Google: ソーシャルログイン
- GitHub: ソーシャルログイン
- Neon: 学習記録データベース
- Vercel: ホスティングおよび実行基盤

これらの第三者サービスは、それぞれ独自のプライバシーポリシーや利用条件に基づいて情報を取り扱います。

## 7. 第三者提供

本サービスは、次の場合を除き、個人情報を第三者へ提供しません。

- ユーザー本人の同意がある場合
- 法令に基づき開示が求められる場合
- サービス運営上必要な範囲で、認証、ホスティング、データ保存等の委託先サービスを利用する場合

## 8. 保存期間と削除

- アカウントに紐づく学習記録は、サービス運営上必要な期間保存されます。
- 未ログイン時の一時進捗は、ブラウザの `sessionStorage` にのみ保存され、ブラウザセッションの終了等により失われる場合があります。
- アカウント連携の取り消しは、Google または GitHub の各設定画面から行えます。
- アカウント削除や学習記録削除の正式機能は、提供状況に応じて別途案内します。

## 9. セキュリティ

本サービスは、認証、保存、送信、アクセス制御において、合理的な範囲で安全管理措置を講じます。ただし、インターネット上の通信や保存方式について、完全な安全性を保証するものではありません。

## 10. ユーザーの選択肢

ユーザーは、次の選択を行えます。

- Email、Google、GitHub のいずれかの認証方法を選ぶ
- Google または GitHub のアカウント設定から、本サービスへの連携を解除する
- 未ログインのまま一部機能を利用する
- 本サービスの利用を中止する

## 11. 未成年の利用

未成年の方は、必要に応じて保護者の同意を得たうえで本サービスを利用してください。

## 12. ポリシーの改定

本ポリシーは、法令、サービス内容、利用する外部サービス、認証方式の変更などに応じて改定することがあります。重要な変更がある場合は、公開ページの更新その他の適切な方法で通知します。

## 13. 適用開始日

本ポリシーは、2026-05-08 から適用します。
